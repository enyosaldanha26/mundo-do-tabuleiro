Abra pelo servidor local para jogar no computador

Você abriu o arquivo index.html diretamente do disco. Por segurança do navegador, os módulos JavaScript dos jogos precisam rodar via servidor web local.

Dê dois cliques no arquivo Abrir-Site-Local.bat na pasta do projeto para abrir tudo funcionando perfeitamente! (Quando estiver publicado em mundodotabuleiro.com.br, funciona direto ao clicar.)
